## 1. 快速上手

### 上电后看到什么

```
┌──────────────────────────────────────────────────────────┐
│ WAVE  100us/div      PA1      TRIG:↑ AUTO          RUN   │
├──────────────────────────────────────────────────────────┤
│      ·     ·     ·     ·     ·     ·     ·     ·        │
│   ─────────────────────────────────────────────────      │
│      ·     ·     ·     ·     ·     ·     ·     ·        │
│   - - - - - - - 触发电平虚线 - - - - - - - - - - -      │
├──────────────────────────────────────────────────────────┤
│ Vpp 0.02V   ----   Vrms 0.01V                            │
└──────────────────────────────────────────────────────────┘
```

| 区域 | 内容 |
|---|---|
| 顶部状态栏 | 显示模式、时基、当前通道、触发设置、运行状态 |
| 中间波形区 | 10×8 网格，青色波形曲线，琥珀色虚线为触发电平 |
| 底部测量栏 | Vpp、频率、Vrms 自动测量结果 |

### 三步看到波形

| 步骤 | 操作 |
|---|---|
| 1 | 把待测信号接到 **PA1**，信号地接到开发板 **GND** |
| 2 | 按 `WK_UP` 短按切到 `TIME` 页，用 `KEY0`/`KEY1` 调到合适的时基 |
| 3 | 按 `WK_UP` 短按切到 `TRIG` 页，用 `KEY0`/`KEY1` 把触发电平调到波形中间位置 |

**没有任何信号源时**：把 PA1 接到 GND，应看到一条贴近屏幕底部的直线。这说明设备工作正常。

## 2. 按键详解

板上有三个独立按键，通过**短按 / 长按 / 连发 / 双击**四种事件覆盖全部操作。

### 物理位置

| 按键 | 板载丝印 | 位置 |
|---|---|---|
| KEY1 | `KEY1` / `KEY_UP` | 板边，偏上 |
| KEY0 | `KEY0` | 板边，偏下 |
| WK_UP | `WK_UP` | 板中央 |

### 功能总表

| 操作 | 效果 |
|---|---|
| `KEY1` 短按 | 当前参数 **+1 档** |
| `KEY0` 短按 | 当前参数 **-1 档** |
| `KEY1`/`KEY0` 长按 | **连发**，每 150ms 重复一次（快速扫过参数范围） |
| `WK_UP` 短按 | 切换**参数页** |
| `WK_UP` 长按 | 切换**显示模式**（波形 ↔ 频谱） |
| `WK_UP` 双击 | 重新武装**单次触发** |

> **连发手感**：按住不放，0.6 秒后开始自动重复。调触发电平时特别好用。

### 四个参数页

`WK_UP` 短按在这四页间循环，状态栏会显示当前页名：

| 参数页 | 状态栏显示 | KEY1 / KEY0 的作用 |
|---|---|---|
| **时基** | `TIME 100us/div` | 切换时基档位（7 档） |
| **通道** | `CH PA1` | 切换输入通道（PA1 ~ PA7） |
| **触发** | `TRIG 1.65V` | 调节触发电平 |
| **模式** | `MODE ↑ AUTO` | KEY1 切换采集模式；KEY0 切换触发边沿 |

## 3. 界面元素说明

### 状态栏

| 元素 | 示例 | 说明 |
|---|---|---|
| 显示模式 | `WAVE` / `FFT` | 当前是波形还是频谱 |
| 参数页与取值 | `100us/div` | 当前参数页的设定值 |
| 运行状态 | `RUN` / `HOLD` | RUN 为持续采集；HOLD 表示单次触发已捕获并停止 |

> `RUN` 的**颜色**也有含义：青色表示本屏数据是有效触发对齐的；灰色表示未找到触发点、当前为自由滚动显示。

### 波形区

| 元素 | 说明 |
|---|---|
| 暗色网格 | 横向 10 格、纵向 8 格 |
| 加亮中心横线 | 纵向中点，作为 0V / 3.3V 的参考位置 |
| 青色曲线 | 波形，颜色越亮表示信号越强 |
| 琥珀色虚线 | 触发电平位置，波形穿越此线即触发 |

### 测量栏

| 元素 | 说明 |
|---|---|
| `Vpp` | 峰峰值电压 |
| 中间数值 | 信号频率，无法测量时显示 `----` |
| `Vrms` | 有效值电压 |

## 4. 时基档位怎么选

时基决定"一屏能显示多长时间的信号"，是使用中最常调节的参数。

| 档位 | 采样率 | 每格时间 | 一屏时间 | 适合观察 |
|---|---|---|---|---|
| 1 | **10 kHz** | 3.2 ms | 32 ms | 音频、PWM、传感器输出 |
| 2 | 5 kHz | 6.4 ms | 64 ms | 音频低频段、机械动作 |
| 3 | 2 kHz | 16 ms | 160 ms | 慢变信号、电源波动 |
| 4 | 1 kHz | 32 ms | 320 ms | 人工操作信号、缓慢漂移 |
| 5 | 100 Hz | 320 ms | 3.2 s | 极慢变化、温度类信号 |
| 6 | 10 Hz | 3.2 s | 32 s | 长周期变化观察 |

### 怎么算需要哪一档

**屏幕上最好显示 2 ~ 5 个完整周期。**

```
需要的一屏时间 = 信号周期 × 3
```

| 信号频率 | 周期 | 建议一屏时间 | 建议档位 |
|---|---|---|---|
| 50 Hz | 20 ms | 60 ms | 档位 1 或 2 |
| 100 Hz | 10 ms | 30 ms | 档位 1 |
| 1 kHz | 1 ms | 3 ms | 档位 1 |
| 5 kHz | 200 µs | 600 µs | 档位 1 |

> 本设备的采样率上限为 10 kHz，因此**只能观测 5 kHz 以下的信号**
> （按采样定理，至少需要 2 倍于信号频率的采样率）。

**调法**：先按当前档位看一眼，波形太挤（周期太多）就往慢调，波形太散（不到一个周期）就往快调。

### ⚠️ 关于采样率上限

本设备最高采样率为 **10 kHz**，这是「ADC 转换 + DMA 搬运」的实际吞吐能力决定的，
而不是 ADC 的理论极限。原因是屏幕刷新时 CPU 全速写 GPIO 数据总线，
DMA 取走 ADC 结果的时机被推迟。

实际影响：

| 信号频率 | 能否观测 |
|---|---|
| 10 Hz ~ 1 kHz | ✅ 显示良好，测量准确 |
| 1 kHz ~ 2 kHz | ✅ 可观测，波形略有失真 |
| 2 kHz ~ 5 kHz | ○ 勉强可见，幅度与频率测量偏差增大 |
| > 5 kHz | ❌ 无法可靠观测 |

## 5. 采集模式怎么选

在 `MODE` 参数页用 `KEY1` 切换。

| 模式 | 状态栏 | 行为 | 适用场景 |
|---|---|---|---|
| **AUTO** | `AUTO` | 找到触发点就对齐显示；找不到就自由滚动 | **日常默认**，任何信号都能看到 |
| **NORM** | `NORM` | 只在找到触发点时更新，否则冻结上一屏 | 观察间歇出现的信号（如偶发脉冲） |
| **SING** | `SING` | 捕获到一次边沿后停止，状态栏显示 `HOLD` | **抓单次事件**（按键抖动、上电瞬间） |

### 单次模式的使用流程

```
1. 切到 SING 模式
2. 调好时基与触发电平（此时可能还没触发）
3. 触发条件满足 → 自动捕获一屏 → 状态栏变 HOLD
4. 观察波形
5. 双击 WK_UP 重新武装，等待下一次
```

> **单次模式的技巧**：先用 AUTO 模式调好参数，再切到 SING 等待触发，避免反复试错。

## 6. 触发调节技巧

触发是让波形"稳住不跑"的关键。

### 触发电平调到哪里合适

**调到波形幅度的中间位置**最稳：

```
幅度 0 ~ 3.3V 的信号  →  触发电平调到约 1.65V
幅度 1.0 ~ 2.0V 的信号  →  触发电平调到约 1.5V
```

界面上那条**琥珀色虚线**就是触发电平，把它移到波形上下摆动范围的中间即可。

### 边沿怎么选

| 边沿 | 状态栏 | 何时用 |
|---|---|---|
| 上升沿 `↑` | `TRIG ↑` | 观察信号的"开始"（默认） |
| 下降沿 `↓` | `TRIG ↓` | 观察信号的"结束"，或信号为负逻辑 |

在 `MODE` 参数页用 `KEY0` 切换。

### 波形还是乱跑怎么办

按顺序排查：

| 检查 | 处理 |
|---|---|
| 触发电平是否在波形范围内 | 若虚线在波形上方或下方，永远触发不到 → 调到中间 |
| 时基是否太慢 | 屏上不足一个周期时找不到触发点 → 调快时基 |
| 采集模式是否为 NORM | NORM 模式下无触发就冻结 → 切到 AUTO |
| 信号本身是否抖动 | 若信号带噪声，触发电平附近的噪声会造成随机触发 → 这是正常现象，可尝试把电平调离噪声区 |

## 7. 测量读数怎么理解

### Vpp（峰峰值）

一屏数据中最大值与最小值之差，是最能反映信号幅度的参数。

| 信号类型 | Vpp 与幅度的关系 |
|---|---|
| 方波 0 ~ 3.3V | Vpp ≈ 3.3V |
| 正弦波，偏置 1.65V，幅度 ±1V | Vpp ≈ 2.0V |
| 直流信号 | Vpp ≈ 0V |

### Vrms（有效值）

按 `sqrt(mean(v²))` 计算，反映信号的能量。

| 信号类型 | Vrms 与 Vpp 的关系 |
|---|---|
| 直流 | Vrms = 平均值 = 电压值 |
| 方波（占空比 50%） | Vrms ≈ Vpp / 2（叠加偏置时需另算） |
| 正弦波 | Vrms ≈ Vpp / 2.83 |

> **Vrms 的实用价值**：判断信号"等效于多高的直流"，常用于评估信号功率。

### 频率

由信号跨越中点的间隔推算。

| 显示 | 含义 |
|---|---|
| `1.00kHz` | 测得频率 1 kHz |
| `----` | 屏上不足两个完整周期，无法测量 |

**提高频率测量准确度的办法**：

1. 调节时基，让屏上出现 **3 ~ 5 个完整周期**（周期太少会放大误差）
2. 确保触发电平在中点附近（算法就是用中点作判决）
3. 若信号谐波丰富导致读数跳动，改用 FFT 频谱模式看主频

### 读数的可信度

| 项目 | 说明 |
|---|---|
| 电压精度 | 约 ±1%，受 3.3V 参考电压精度与 ADC 线性度影响。若需更准，可用万用表量出实际 3.3V 值并修改 `OSC_VREF_MV` |
| 电压分辨率 | 约 0.8 mV/LSB（3.3V / 4095） |
| 频率精度 | 取决于时基与信号形状，一般 1% ~ 5% |
| 时间精度 | 各档位的时间基准均由定时器分频精确决定，误差在 1% 以内 |

## 8. 频谱模式

按 `WK_UP` **长按**切换。

### 界面说明

```
┌──────────────────────────────────────────────────────────┐
│ FFT   Fs 100kHz                                      FFT │
├──────────────────────────────────────────────────────────┤
│                                    ██                    │
│                          ██        ██                    │
│         ██       ██      ██        ██       ██           │
│  ██     ██       ██      ██        ██       ██     ██    │
├──────────────────────────────────────────────────────────┤
│ PEAK 1.00kHz                          bias 1.65V         │
└──────────────────────────────────────────────────────────┘
```

| 元素 | 说明 |
|---|---|
| 柱状图 | 横向 64 列，代表 0 ~ 采样率/2 的频率范围 |
| 柱高 | 该频段的信号强度（对数刻度，30 dB 动态范围） |
| 亮青色柱 | 强度 > 60% 的显著谱线 |
| `PEAK` | 最强谱线对应的频率 |

### ⚠️ 必须加直流偏置

**这是频谱模式最重要的前提**：

| 情况 | 结果 |
|---|---|
| 信号加了 1.65V 偏置 | ✅ 波形完整，频谱正确 |
| 信号直接接入（无偏置） | ❌ 负半周被钳位在 0V，波形严重失真，频谱出现大量虚假谐波 |

**为什么要偏置**：ADC 只能采集 0 ~ 3.3V 的正电压。无偏置的交流信号负半周落到 0V 以下，被引脚内部二极管钳位，原始波形已被破坏，FFT 自然算不对。

### 怎么看频谱

| 现象 | 含义 |
|---|---|
| 某个柱子明显突出 | 该频率为主要成分（基频或强谐波） |
| 等间隔的多根柱子 | 信号的各次谐波（方波、三角波都有丰富谐波） |
| 低频段整体抬起 | 信号含直流或低频漂移 |
| 柱子密集杂乱 | 信号含噪声，或输入幅度太小 |

## 9. 自检验证

没有信号源也能验证设备是否正常。

### 测试一：接地看直线

| 操作 | 期望结果 |
|---|---|
| 把 PA1 用杜邦线接到 GND | 波形变成**贴近屏幕底部的直线** |
| 测量栏 | `Vpp` 接近 0.00V |

**这是最基本的验证**：能看到稳定直线，说明 ADC 采样、DMA 搬运、屏幕绘制整条链路都是通的。

### 测试二：接 3.3V 看顶线

| 操作 | 期望结果 |
|---|---|
| 把 PA1 接到开发板的 3.3V 引脚 | 波形变成**贴近屏幕顶部的直线** |
| 测量栏 | `Vpp` 仍接近 0（因为是直流），但波形位置在最上方 |

### 测试三：悬空看噪声

| 操作 | 期望结果 |
|---|---|
| PA1 什么都不接 | 波形为随机抖动的一条线 |

悬空引脚会拾取环境电磁噪声，读数乱跳是**正常现象**，不是故障。

### 测试四：用 PWM 自测（推荐）

让开发板自己产生信号，是最可靠的验证方式：

```
用 TIM 输出一路 1kHz 的 PWM  →  接到 PA1  →  应看到方波
```

这样能看到规则的方波，同时验证了时基、触发与测量功能。

## 10. 常见问题

### 显示类

**Q：屏幕全白 / 花屏**

| 原因 | 处理 |
|---|---|
| TFT 排线松动 | 断电后重新插紧（两头都检查） |
| PB3/PB4 未释放 | 程序已处理；若改动过 `main.c`，确认 `KEY_Init()` 在 `osc_ui_init()` 之前调用 |

**Q：屏幕亮着但波形区全黑**

程序卡住了。检查串口输出（9600 波特率）是否有 `Mini Oscilloscope boot`，若无输出说明初始化未完成。

### 波形类

**Q：完全没有波形 / 屏上没东西**

| 检查项 | 说明 |
|---|---|
| 共地了吗 | 信号源与开发板必须共地，这是最常见的原因 |
| 信号在 0 ~ 3.3V 内吗 | 超出范围会被钳位 |
| 时基合适吗 | 太快会导致波形只占屏幕极左一小段 |
| 触发电平在哪 | 若虚线在波形范围之外，AUTO 模式下会自由滚动，波形仍应可见 |

**Q：波形一直乱跑不停**

触发电平不在波形范围内，或采集模式为 AUTO 且无有效触发。把触发电平调到波形中间。

**Q：波形是直线但读数不为 0**

直流电压输入。这是正常的——直线的高度就代表这个直流电压值。

**Q：波形上下都被削平了**

信号超出 0 ~ 3.3V 范围，被引脚钳位。请降低信号幅度或加偏置。

### 按键类

**Q：按键没反应**

| 检查项 | 处理 |
|---|---|
| 是否按对按键 | 板上有三个按键，确认丝印 |
| 长按是否生效 | 长按需持续 0.6 秒以上 |
| KEY0/KEY1 无反应 | 这两个键只在有参数页时才起作用，按 `WK_UP` 切页试试 |

**Q：参数调不动**

若当前在 `MODE` 页，`KEY1` 切换模式只有 3 个选项、`KEY0` 切换边沿只有 2 个选项，看起来变化不明显。按 `WK_UP` 切到 `TIME` 页调时基最直观。

### 测量类

**Q：频率一直显示 `----`**

屏上不足两个完整周期。调慢时基（增大每格时间）让波形显示更多周期。

**Q：Vpp 读数比实际大**

| 原因 | 处理 |
|---|---|
| 信号带噪声 | 噪声尖峰会被计入最大值/最小值，属正常现象 |
| 探头或导线拾取干扰 | 缩短接线，远离干扰源 |

**Q：Vpp 读数比实际小**

信号超出 0 ~ 3.3V 被钳位，或时基太快导致采样点稀疏、漏掉峰值。

### 频谱类

**Q：频谱一片杂乱没有明显峰值**

| 原因 | 处理 |
|---|---|
| 没加直流偏置 | 加约 1.65V 偏置 |
| 信号幅度太小 | 增大信号幅度 |
| 时基不合适 | 调整时基，使采样率与信号频率匹配 |

**Q：Peak 频率一直跳动**

信号弱或噪声大。增大信号幅度，或让信号更纯净。

## 11. 使用建议与注意事项

### ⚠️ 安全注意

| 事项 | 说明 |
|---|---|
| **绝对不要输入超过 3.3V** | 会永久损坏单片机引脚，**没有保护电路** |
| **不要输入负电压** | 会被内部二极管钳位，可能造成大电流 |
| **测量未知信号前先确认幅度** | 可先用万用表量一下 |
| **不要测市电** | 220V 会直接炸掉芯片，必须经过隔离与衰减 |

### 提高测量准确度的技巧

| 技巧 | 说明 |
|---|---|
| 让屏上显示 3 ~ 5 个周期 | 太少会放大频率测量误差 |
| 触发电平放在波形中点 | 与频率算法使用的判决电平一致 |
| 缩短信号线 | 减少拾取干扰 |
| 校准参考电压 | 用万用表量出开发板实际 3.3V 值，修改 `OSC_VREF_MV` |
| 用于 1 kHz 以下信号 | 该范围内采样率充裕，测量最准确 |

### 日常维护

| 周期 | 项目 |
|---|---|
| 使用前 | 接地自检一次（PA1 接 GND 看直线） |
| 长期不用 | 存放于干燥环境 |
| 读数异常时 | 重新做接地自检，确认是设备问题还是信号问题 |
