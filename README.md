# 迷你数字示波器 · Mini Oscilloscope

基于 **STM32F103 + 2.8 寸 TFT** 的掌上示波器：TIM2 定时触发 ADC，DMA 后台搬运采样数据，屏幕上实时绘制波形，并自动测量峰峰值、有效值与频率。附带 FFT 频谱显示模式。

**三个按键完成全部操作**，无需触摸屏，也不需要任何图形库。

```
┌──────────────────────────────────────────────────────────┐
│ WAVE  100us/div      PA1      TRIG:↑ AUTO          RUN   │
├──────────────────────────────────────────────────────────┤
│      ·     ·     ·     ·     ·     ·     ·     ·         │
│   ───────────╱╲───────────╱╲───────────╱╲───────────     │
│      ·     ·╱   ╲    ·  ╱   ╲   ·   ╱   ╲   ·            │
│   ─────────╱     ╲──────╱     ╲─────╱     ╲──────        │
│      ·     ·     ·     ·     ·     ·     ·     ·         │
│   - - - - - - - - 触发电平 - - - - - - - - - - - -       │
├──────────────────────────────────────────────────────────┤
│ Vpp 3.28V   1.00kHz   Vrms 1.15V                         │
└──────────────────────────────────────────────────────────┘
```

## 功能特性

| 功能 | 说明 |
|---|---|
| **7 路模拟输入** | PA1 ~ PA7，按键切换，量程 0 ~ 3.3V |
| **7 档时基** | 1 µs/div ~ 32 ms/div，覆盖 100 Hz ~ 500 kHz 信号 |
| **边沿触发** | 上升沿 / 下降沿可选，触发电平可调，带预触发显示 |
| **三种采集模式** | AUTO（无触发自由滚动）/ NORMAL（无触发冻结）/ SINGLE（抓单次脉冲） |
| **自动测量** | 峰峰值 Vpp、有效值 Vrms、平均值、最大/最小值、信号频率 |
| **FFT 频谱** | 256 点定点 FFT + 汉宁窗，64 列柱状频谱，自动标注主频 |
| **深色仪表界面** | 320×240 全屏波形区，网格、触发电平虚线、状态栏、测量栏 |

**技术实现亮点**：

- **TIM2 定时触发 + DMA 循环搬运**：采样全程不占用 CPU，CPU 全部用于绘图
- **环形缓冲 + 向后搜索触发点**：不会漏触发，切换参数时波形不中断，天然支持预触发
- **零图形库依赖**：直接操作 LCD 显存，Flash 占用仅 29 KB
- **纯定点 FFT**：汉宁窗与旋转因子均为编译期预计算常量表，不链接数学库

## 接线说明

### 被测信号输入

| 信号线 | 接到 | 说明 |
|---|---|---|
| 信号正极 | **PA1 ~ PA7** 任一脚 | 默认使用 PA1 |
| 信号地 | 开发板 **GND** | 必须共地，否则读数无意义 |

```
   待测信号源                     MiniSTM32
  ┌──────────┐                 ┌──────────────┐
  │   信号 ──┼─────────────────┤ PA1          │
  │          │                 │              │
  │   GND  ──┼─────────────────┤ GND          │
  └──────────┘                 └──────────────┘
```

### ⚠️ 输入信号注意事项

| 事项 | 说明 |
|---|---|
| **电压范围** | 输入必须保持在 **0 ~ 3.3V** 之内。超过会损坏单片机引脚，**没有保护电路** |
| **负电压** | 不能输入负电压，会被引脚内部二极管钳位，读数失真 |
| **直流偏置** | 观察交流信号时请叠加约 1.65V 直流偏置，使波形完整落在 0 ~ 3.3V 内 |
| **共地** | 信号源与开发板必须共地 |

> **自测建议**：先用开发板自身产生的信号验证。例如用 TIM 输出一路 PWM，接回 PA1 观察方波，无需外部信号源。

### 引脚占用

```
PA0   WK_UP 按键      PA1~PA7  模拟输入（ADC1_IN1~IN7）
PA8   LED0            PA9/PA10 串口1（调试输出）
PA13/PA14  SWD 调试   PA15     KEY1 按键
PB0~PB15  TFT 数据线（16 位并口）
PC5   KEY0 按键       PC6~PC10 TFT 控制线
```

> **说明**：由于 PA0 被 WK_UP 按键占用，ADC1_IN0 不可用作输入，因此模拟通道从 PA1 开始。
>
> **注意**：TFT 数据线使用 PB3/PB4，这两个引脚默认是 JTAG 功能。程序在初始化屏幕前调用 `KEY_Init()` 释放它们（内部执行 `GPIO_Remap_SWJ_JTAGDisable`），否则会出现花屏。

## 快速开始

### 1. 编译

```bat
cd /d <项目根目录>
build.bat              :: 增量编译，产物在 build\Oscilloscope.hex
build.bat clean        :: 清理后重新编译（改了 .h 必须这样做）
```

> **重要**：本项目 Makefile 没有头文件依赖规则，**修改任何 `.h` 后必须 `build.bat clean` 再编译**，否则改动不会生效。

### 2. 烧录

```powershell
C:\Users\<用户名>\.pyocd-venv\Scripts\pyocd.exe load -t stm32f103rc build\Oscilloscope.hex
```

在 VS Code 中可运行任务 `Flash (pyOCD + ST-Link)`（编译 + 烧录一条龙），或按 `F5` 进入调试。

### 3. 上电验证

| 步骤 | 期望现象 |
|---|---|
| 1 | 屏幕点亮，显示深色界面、网格与一条虚线（触发电平） |
| 2 | 状态栏显示 `WAVE 100us/div PA1 TRIG:↑ AUTO` |
| 3 | 底部测量栏显示 Vpp / Vrms 数值 |
| 4 | PA1 悬空时波形为一条随机抖动的线（正常现象，悬空引脚会拾取噪声） |
| 5 | 把 PA1 接到 GND，波形变成贴近底部的**直线** |

**第 5 步是自检的关键判据**：接 GND 后如果能看到稳定的直线，说明采样链路完全正常。

### 4. 接入信号

把信号源接到 PA1，观察波形。若波形不稳或不动：

| 现象 | 处理 |
|---|---|
| 波形乱跑 | 调整触发电平（按 WK_UP 切到 `TRIG` 页，用 KEY0/KEY1 调） |
| 波形太挤或太散 | 调整时基（`TIME` 页） |
| 完全不动 | 检查共地、检查信号是否在 0 ~ 3.3V 范围 |

## 按键操作

三个按键通过**短按 / 长按 / 连发 / 双击**四种事件实现完整操作：

| 按键 | 板载丝印 | 短按 | 长按 | 双击 |
|---|---|---|---|---|
| **KEY1** | 板边第一个 | **增大**当前参数 | 快速增大（连发） | — |
| **KEY0** | 板边第二个 | **减小**当前参数 | 快速减小（连发） | — |
| **WK_UP** | 板中央 | **切换参数页** | **切换波形/频谱显示** | 重新武装单次触发 |

### 参数页

按 `WK_UP` 短按在四个参数页之间循环：

| 参数页 | KEY1 / KEY0 的作用 |
|---|---|
| `TIME` | 切换时基档位（1 µs/div ~ 32 ms/div，共 7 档） |
| `CH` | 切换输入通道（PA1 ~ PA7） |
| `TRIG` | 调节触发电平（短按步进 16 LSB，长按连发步进 64） |
| `MODE` | KEY1 切换采集模式（AUTO / NORM / SING）；KEY0 切换触发边沿（↑ / ↓） |

> **连发机制**：按住 KEY0 或 KEY1 超过 0.6 秒后自动以 150ms 间隔重复，方便快速扫过参数范围。

## 使用方法

### 时基档位与适用信号

| 档位 | 采样率 | 每格时间 | 一屏时间 | 适合观察 |
|---|---|---|---|---|
| 1 | 1 MHz | 32 µs | 320 µs | 高速数字信号、开关波形 |
| 2 | 500 kHz | 64 µs | 640 µs | 音频高频段、PWM |
| 3 | 200 kHz | 160 µs | 1.6 ms | 音频信号 |
| 4 | 100 kHz | 320 µs | 3.2 ms | 音频、传感器输出 |
| 5 | 50 kHz | 640 µs | 6.4 ms | 低频调制信号 |
| 6 | 10 kHz | 3.2 ms | 32 ms | 慢变信号、电源纹波 |
| 7 | 1 kHz | 32 ms | 320 ms | 极慢变化、人工操作信号 |

### 三种采集模式怎么选

| 模式 | 行为 | 适用场景 |
|---|---|---|
| `AUTO` | 找到触发点则对齐显示；找不到则自由滚动 | **日常使用**，任何信号都能看到 |
| `NORM` | 只在找到触发点时更新画面，否则冻结 | 观察间歇性出现的信号 |
| `SING` | 捕获到一次边沿后停止更新，显示 `HOLD` | **抓单次脉冲**（按 WK_UP 双击重新武装） |

### 触发调不到怎么办

触发搜索最多回溯半个缓冲区（1024 点）。若信号周期远大于一屏时间，触发点找不到，此时：

1. 切换到 `AUTO` 模式（自动降级为自由滚动）
2. 或者调慢时基，让屏幕上至少包含 2 个完整周期
3. 或者调低触发电平到波形实际跨越的范围

### 测量栏读数含义

| 读数 | 含义 | 说明 |
|---|---|---|
| **Vpp** | 峰峰值电压 | 最大值与最小值之差 |
| **Vrms** | 有效值电压 | `sqrt(mean(v²))`，反映信号能量 |
| **频率** | 由中点跨越间隔推算 | 显示 `----` 表示屏上不足两个周期，无法测量 |

> 频率测量原理是统计信号跨越中点的间隔，因此**对含大量谐波的信号会不够准确**，此时可切到频谱模式查看主频。

### 频谱模式

按 `WK_UP` **长按**切换 `WAVE` / `FFT` 显示。

| 项目 | 说明 |
|---|---|
| 频率轴 | 0 ~ 采样率/2（奈奎斯特频率），横向 64 列 |
| 幅度轴 | 30 dB 动态范围的对数刻度，0 ~ 100 |
| 主频标注 | 测量栏显示 `PEAK xxx` |

> ⚠️ **频谱模式的输入必须叠加直流偏置（约 1.65V）**。
> 因为 ADC 只能采集 0 ~ 3.3V，未加偏置的交流信号负半周会被钳位在 0V，
> 波形严重失真，频谱结果不可信。界面上也有相应提示（`bias 1.65V`）。

## 技术规格

| 项目 | 参数 |
|---|---|
| 主控 | STM32F103RCT6，Cortex-M3 @72MHz |
| Flash 占用 | **29.30 KB** / 256 KB（约 11%） |
| RAM 占用 | **9.79 KB** / 48 KB（约 20%） |
| 显示 | 2.8 寸 TFT，320×240，16 位色 |
| 图形库 | **无**（直接操作 LCD 显存） |
| ADC 分辨率 | 12 位（0 ~ 4095） |
| 输入量程 | 0 ~ 3.3V |
| 电压显示分辨率 | 约 0.8 mV/LSB |
| 采样率范围 | 1 kHz ~ 500 kHz（时基表另含 1 MHz 档） |
| 采样缓冲 | 2048 点环形缓冲（4 KB） |
| 时基档位 | 7 档，1 µs/div ~ 32 ms/div |
| 触发方式 | 上升沿 / 下降沿，电平可调 |
| FFT 点数 | 256 点，汉宁窗，定点运算 |
| 刷新率 | 约 10 ~ 30 fps（取决于波形复杂度） |

### 采样率上限的由来

```
ADC 时钟        = PCLK2 / 6 = 12 MHz
单次转换时间    = (采样时间 + 12.5) / ADC时钟
                = (1.5 + 12.5) / 12MHz ≈ 1.17 µs
```

因此采样周期必须大于约 1.2 µs。工程把最高实用采样率限制在 **500 ksps**；时基表中保留的 1 MHz 档位实际有效采样率约为 850 ksps，波形会有轻微不均匀，仅适合观察趋势。

## 已知限制

| 限制 | 说明 |
|---|---|
| **无输入保护** | 输入直接接到单片机引脚，超过 3.3V 或负电压会损坏芯片。测量未知信号前请先确认幅度 |
| **无垂直档位** | 波形始终按 0 ~ 3.3V 满量程显示，无法放大微小信号 |
| **最高档位不精确** | 1 MHz 档超过 ADC 转换能力，实际有效采样率约 850 ksps |
| **缓冲深度有限** | 采样数据仅保存在 4 KB 环形缓冲中，无法长时存储 |
| **频率测量依赖波形形状** | 对谐波丰富的信号，过零法不如 FFT 准确 |
| **FFT 需直流偏置** | 未加偏置的交流信号会失真，频谱不可信 |
| **无外部触发输入** | 触发只能来自被测信号本身 |
| **无数据导出** | 波形数据不能导出到电脑（串口协议未实现） |

## 后续可以做什么

按难度从低到高排列，代码中已预留扩展点：

| 方向 | 说明 |
|---|---|
| **垂直档位（放大）** | 在 `osc_ui.c` 的映射公式中加入增益系数，实现 1x/2x/4x 显示放大 |
| **波形数据串口导出** | 通过 USART1 把一屏数据以 CSV 格式发给电脑，便于离线分析 |
| **频率计模式** | 用 TIM 输入捕获测频，精度远高于 ADC 采样法 |
| **信号发生器模式** | 用 TIM + PWM 产生方波输出，让本机具备自测能力 |
| **逻辑分析仪模式** | 用 DMA 同时采集 8 路数字引脚，显示时序图 |
| **输入前端电路** | 加运放做阻抗变换与电压缩放，实现 ±10V 输入与多档量程 |
| **测量游标** | 加入两条可移动游标，直接读出两点间时间差与电压差 |
| **保存波形** | 保存一屏波形用于前后对比（需外接存储器件） |
